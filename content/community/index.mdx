# Community

## 概要

> 実装状況: Community関連のDB定義は一部存在しますが、本ページで定義するCommunity機能と整合性制約は未実装です。

Communityは、家族や友人などがMediaを共有する閉じた独立空間です。Mediaと並ぶ独立したProduct domainとして、参加、権限、招待、共有、分類、削除の方針を管理します。

## 目的と対象範囲

- 家族や知人が静止画像を安全に共有できる閉じた空間を提供する。
- Community、Membership、Administrator、招待URL、参加申請を管理する。
- User管理Mediaの共有とCommunity管理Mediaの直接Uploadを区別する。
- Community内のGroup・Tagによる共同整理を扱う。
- Community同士をネストせず、参加者、Media、権限を継承しない。

## 主要概念

| 概念 | 意味 |
| --- | --- |
| Community | 家族や知人がMediaを共有する閉じた独立空間 |
| Membership | UserとCommunityの有効な参加関係 |
| Administrator | admin roleのMembershipを持ち、参加・設定・権限を管理するUser |
| 招待URL | Administratorが発行する、Communityへの参加を開始するためのURL |
| User起点Join Request | Invitationとは独立した将来の参加申請 |
| Media共有 | User CustodianがCommunity参加者に閲覧を許可する操作 |
| Community管理Media | CommunityがCustodianであるMedia |

## 制約と責務境界

- Communityごとに少なくとも1人のAdministratorを維持し、Administrator専用entityは設けない。
- Communityは閉じた独立空間とし、別Communityへ参加者、Media、権限を継承しない。
- Community domainはCommunity、Membership、Invitation、User起点Join Requestを所有する。
- MediaのCustody、共有関係、Media削除はMedia domainを正本とする。
- Userの認証主体とaccount lifecycleはUser domainを正本とする。
- Group・Tagは分類に使用し、Mediaの管理主体や閲覧権限を変更しない。
