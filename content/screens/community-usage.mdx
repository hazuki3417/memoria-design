# Community Usage

## 概要

Community Usageは、現在選択中のCommunityがCustodianであるMedia Originalの保存状況を確認する画面です。Personal accountや他Communityの使用量は含みません。

Community contextのSide Menuから、現在のCommunityの全Active Memberが閲覧できます。User Settings > Usageと共通のUsage表示UIを使用し、表示data sourceだけをCommunity scopeに分けます。

## 表示情報

### Storage Usage

Initial Releaseでは、各Communityに独立した **5 GB**（5,000,000,000 bytes）の上限を適用します。別Community、または同じUserのPersonal accountとは連動しません。

画面では現在の使用量、5 GBの上限、残容量または使用率、および登録済みOriginalの総件数を提示します。容量表示はPreferencesで選択したファイルサイズ単位に従います。Initial Releaseの初期値はDecimalです。Usage画面のページ見出し右側に表示切替を1つ設けます。切替は容量をTabler Iconsのデータベースアイコン（IconDatabase）、割合をパーセントアイコン（IconPercentage）で示すコンパクトな二択です。両選択肢には「容量で表示」「割合で表示」のTooltipとスクリーンリーダー向けの名前を用意し、キーボード操作と明確な選択状態を維持します。Compact表示では見出しの下へ折り返します。初期値は容量で、切替操作はStorageの「使用済み」「空き容量」と形式別内訳の表示値に同時に適用します。両方の数値を同時併記せず、必要に応じて切り替えて確認できます。容量上限は表示モードにかかわらず実際の容量値を示し、登録件数とProgress Barの意味・色分けは変えません。切替状態は画面内だけで保持し、Preferencesには保存せず、PersonalとCommunity間でも同期しません。

算入対象は、CommunityがCustodianでMedia登録が確定したOriginal fileのみです。Personal Mediaから共有されているUser Custodian Media、Variant等の派生file、処理中間data、未登録・未確定Uploadは含めません。Original登録後にVariant Processingが失敗してもOriginalは使用量・件数に含めます。

### File format別内訳

登録済みOriginalについて、file formatごとの件数とOriginal byte数から導出した使用量を表示します。

| 表示分類 | 含める拡張子 |
| --- | --- |
| JPEG | .jpg、.jpeg |
| PNG | .png |
| WebP | .webp |
| HEIC / HEIF | .heic、.heif |

JPEGの.jpgと.jpegは一つに統合し、.heicと.heifも一つのHEIC / HEIF行に統合します。format分類はfile extensionやClient申告MIMEではなく、Originalの実内容を検証して確定したcanonical formatを正本とします。表中の拡張子は利用者向けの表示例です。総件数・総使用量は内訳の合計と一致します。形式ごとのMediaを選択・削除・変換するActionはこの画面から提供しません。

形式別内訳は「形式」「登録件数」「使用量」の3列で表示し、見出しは表示切替によらず「使用量」で固定します。最終列の値だけがページ共通の表示切替に応じて容量値または割合値に変わります。割合は当該Personal／Communityのストレージ上限を分母とする値であり、登録済みファイル間の構成比ではありません。割合表示時に表の下へ補足文は常設せず、表示モードと値の単位（%）から読み取れる構成にします。形式・件数・最終列による並べ替えができ、使用量と割合は同一の元のbyte数による順序を共有します。表示を切り替えても並べ替え状態を維持し、丸めた表示値で順序を判断しません。

登録済みOriginalが0件の場合もJPEG、PNG、WebP、HEIC / HEIFの4行を常に表示し、各形式の登録件数および選択中の使用量または割合を0として示します。取得待機中は確定値の0と混同しないようSkeletonを使い、形式別内訳表の見出し・4行・合計フッターという構造を維持します。

## 状態

- **利用あり**: 合計容量・上限・残容量または使用率、登録件数とformat別内訳を表示します。
- **使用量0**: 0 GB・0件の状態を明示し、Personal accountや他Communityの使用量を混在させません。
- **読み込み中**: loading stateを示し、仮の0件・0 byteを実値として表示しません。
- **取得失敗**: Usageが取得できなかったことをEmptyと区別し、再試行可能なActionを提示します。
- **上限到達**: 現在の使用量と上限に達していることを明示します。別contextの残容量を流用できるように見せません。

## Navigation

routeは/communities/[communityId]/usageです。Community contextのSide Menuに「Usage」を表示し、現在のCommunity Usageへ遷移します。別Communityへcontextを切り替えた場合は、そのCommunityのUsage routeへ移動します。

Personal Usageは/settings/usageで確認します。Account MenuからCommunity Usageへは移動せず、Community Usageへの入口はCommunity context navigationに置きます。

## 権限

有効なMembershipを持つAdministrator / MemberはCommunity Usageを閲覧できます。Usage参照を理由に特定roleだけへ閲覧を制限しません。Membershipを失ったUserは対象CommunityのUsageを継続閲覧できません。

## Responsive対応

Compact / Medium / Wideのすべてで、使用量と上限の関係、登録件数、format別内訳を確認できます。狭いviewportでは内訳を縦方向に配置する等presentationを適応させますが、利用可能な情報を省略しません。
