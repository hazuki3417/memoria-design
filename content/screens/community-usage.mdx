# Community Usage

## 概要

Community Usageは、現在選択中のCommunityがCustodianであるMedia Originalの保存状況を確認する画面です。Personal accountや他Communityの使用量は含みません。

Community contextのSide Menuから、現在のCommunityの全Active Memberが閲覧できます。具体的な画面表現はUser Settings > Usageと共通の情報構造を使用できますが、集計dataは現在のCommunityに限定します。

## 表示情報

### Storage Usage

Communityごとに独立した **5 GB**（5,000,000,000 bytes）の上限を適用します。別Community、または同じUserのPersonal accountとは連動しません。

画面では現在の使用量、5 GBの上限、残容量または使用率、および登録済みOriginalの総件数を提示します。容量表示はPreferencesで選択したファイルサイズ単位に従います。Initial Releaseの初期値はDecimalです。

算入対象は、CommunityがCustodianでMedia登録が確定したOriginal fileのみです。Personal Mediaから共有されているUser Custodian Media、Variant等の派生file、処理中間data、未登録・未確定Uploadは含めません。Original登録後にVariant Processingが失敗してもOriginalは使用量・件数に含めます。

### File format別内訳

登録済みOriginalについて、file formatごとの件数とOriginal byte数から導出した使用量を表示します。

| 表示分類 | 含める拡張子 |
| --- | --- |
| JPEG | .jpg、.jpeg |
| PNG | .png |
| WebP | .webp |
| HEIC / HEIF | .heic、.heif |

JPEGの.jpgと.jpegは一つに統合し、.heicと.heifも一つのHEIC / HEIF行に統合します。総件数・総使用量は内訳の合計と一致します。形式ごとのMediaを選択・削除・変換するActionはこの画面から提供しません。

## 状態

- **利用あり**: 合計容量・上限・残容量または使用率、登録件数とformat別内訳を表示します。
- **使用量0**: 0 GB・0件の状態を明示し、Personal accountや他Communityの使用量を混在させません。
- **読み込み中**: loading stateを示し、仮の0件・0 byteを実値として表示しません。
- **取得失敗**: Usageが取得できなかったことをEmptyと区別し、再試行可能なActionを提示します。
- **上限到達**: 現在の使用量と上限に達していることを明示します。別contextの残容量を流用できるように見せません。

## Navigation

routeは/communities/[communityId]/usageです。Community contextのSide Menuに「Usage」を表示し、現在のCommunity Usageへ遷移します。別Communityへcontextを切り替えた場合は、そのCommunityのUsage routeへ移動します。

Personal Usageは/settings/usageで確認します。Account MenuからCommunity Usageへは移動せず、Community Usageへの入口はCommunity context navigationに置きます。

## 権限

有効なMembershipを持つAdministrator / MemberはCommunity Usageを閲覧できます。Usage参照を理由に特定roleだけへ閲覧を制限しません。Membershipを失ったUserは対象CommunityのUsageを継続閲覧できません。

## Responsive対応

Compact / Medium / Wideのすべてで、使用量と上限の関係、登録件数、format別内訳を確認できます。狭いviewportでは内訳を縦方向に配置する等presentationを適応させますが、利用可能な情報を省略しません。
