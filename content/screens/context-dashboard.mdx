# Context Dashboard

## 目的

Personalと各CommunityのDashboardは、現在のContextの最近のMediaを把握し、主要機能へ移動する入口とします。Media Browserの閲覧・絞り込み・一括操作をDashboardへ移さず、各専用画面へ案内します。

## Personal Dashboard

- URL: `/dashboard`。認証・User登録完了後の標準entry。
- 本人がCustodianであるMediaのうち、最近のMediaを表示します。Communityへ共有済みのMediaも、本人がCustodianである限りPersonalの対象です。
- 最近のMediaはDashboard上でread-onlyなpreviewとして表示し、Media単位の選択・Detail表示・Action・Navigationは提供しません。Personal Media全体の閲覧はセクション単位の入口からPersonal Media一覧へ移動します。
- Personal Media一覧、Groups、Context Switcherによる参加中Communityへの移動を、主要機能への入口として提供します。Uploadの開始はPersonal Media画面から行い、DashboardにUpload入口を設けません。
- 最近のMediaがない場合はEmpty Stateとして「メディアはまだありません」と表示し、「メディアへ移動」ActionからPersonal Mediaへ移動できるようにします。補足説明やUpload ActionはDashboardには表示しません。

## Community Dashboard

- URL: `/communities/[communityId]/dashboard`。`communityId`はAPI契約に従う安定識別子です。
- 現在のCommunityで閲覧可能な最近のMediaを表示します。User管理Mediaの共有とCommunity管理Mediaを含め、Custodianと共有の既存権限を変更しません。
- 最近のMediaはDashboard上でread-onlyなpreviewとして表示し、Media単位の選択・Detail表示・Action・Navigationは提供しません。当該CommunityのMedia全体の閲覧はセクション単位の入口からCommunity Media一覧へ移動します。
- Community Media一覧、Groups、Membersへの入口を提供します。ManagementはAdministratorに限り表示します。Uploadは権限に応じてCommunity Media画面から開始し、Dashboardには入口を設けません。
- 閲覧可能なMediaがない場合はEmpty Stateとして「メディアはまだありません」と表示し、「メディアへ移動」ActionからCommunity Mediaへ移動できるようにします。補足説明、Communityへの直接Upload、自分のMediaから共有するActionはDashboardには表示しません。

## 共通の状態・権限

- 最近のMediaは、各ContextのMedia Browserと整合する新しい順の安定した並びを基本とします。Personal・Communityの双方で最大12件を取得・表示します。12件未満なら存在する件数だけを表示し、12件を超える場合は各ContextのMedia一覧へ案内します。ThumbnailはMediaの存在と最近の内容を視覚的に把握するためのread-only previewとし、thumbnail画像だけを表示します。filename、作成日時、Uploader、Custody等の補助情報はDashboardの最近のMediaには表示しません。Media単位の選択、Detail表示、hover Action、Context Menu等のInteractionを持たせません。Media全体を閲覧するNavigationは「最近のメディア」セクション全体に対する「すべて見る」Actionとして提供し、PersonalではPersonal Media、Communityでは現在CommunityのCommunity Mediaへ移動します。Wide / Mediumではセクション見出しの右側を基本とし、Compactでは利用可能幅に応じてセクション末尾等へ配置を変更できます。配置が変わってもMedia単位のActionとして扱わず、意味・label・destinationを維持します。ThumbnailはMedia Browserと同じ正方形thumbnail Variantを利用し、Dashboardの利用可能なcontainer幅へ追従するresponsive gridとして配置します。Compact / Medium / Wideごとの固定列数はProduct仕様にせず、最大12件を通常のgrid内に表示して横スクロールCarouselにはしません。12件未満の場合も空き枠をplaceholderで埋めません。Dashboardは操作可能なMedia Collectionではなくoverviewであるため、User SettingsのMedia thumbnail size（小 / 中 / 大）には連動させず、Dashboardとして安定した閲覧密度を維持します。thumbnail間隔や具体的な寸法はDesign SystemとVisual Reviewで決定します。正常なthumbnail Variantを利用できないMediaでは正常画像が存在するように見せず、Media Browserの状態表現原則に従います。read-only previewを操作可能に見せるhover overlay、拡大表現、pointer cursor等は追加しません。更新タイミングは取得契約の具体化時に決定します。
- LoadingとMediaが0件のEmptyを区別します。取得失敗では空一覧として扱わず、既存の共通エラー表示方針に従います。
- Contextごとに閲覧権限を再評価します。Membership喪失時は当該Communityの保護データを継続表示せず、詳細な原因を示さない共通エラー表示へ移ります。
- Dashboardは独自の閲覧権限を導入せず、Media・Groups・Tag操作・Members等の既存権限を尊重します。
- Compact / Medium / Wideのいずれでも、現在Context、最近のMedia、Media一覧および主要機能への到達性を維持します。具体的なlayoutはStorybookとVisual Reviewで決定します。

## Initial Releaseと後続リリース

- Initial ReleaseにはPersonal・Community双方の最近のMedia（最大12件）と主要機能への入口を含めます。DashboardにはUpload入口を設けず、Uploadは各ContextのMedia画面から開始します。
- Media件数等の統計、および最近の活動履歴はInitial Releaseに含めず、後続リリースで必要性・API負荷・Privacyを検討します。
- 統計・活動履歴の取得APIをDashboardの初回実装の前提としません。
