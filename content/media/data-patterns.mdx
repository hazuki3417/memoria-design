# Mediaデータパターン


## 概要

> 実装状況: ImageとImage Groupの一部は実装済みです。Media Custodian、Community公開、動画、委譲時の公開解除は設計との差分があります。

## 1. User管理Mediaを複数Communityへ公開

```mermaid
flowchart TD
    User["User A（Custodian）"] --> Media["Media 1"]
    Media --> Family["家族Community"]
    Media --> Club["部活Community"]
```

- CustodianはUser Aだけ
- 家族と部活の参加者は同じMediaを閲覧
- Community同士に関係はない
- Mediaを複製しない

## 2. Userが複数Communityへ所属

```mermaid
flowchart TD
    Child["User: 子ども"]
    Family["家族"]
    School["学校"]
    Friends["ゲーム友達"]
    Child --> Family
    Child --> School
    Child --> Friends
```

Userが共通していても、各Communityの参加者・Media・権限は独立します。

## 3. Community管理Media

```mermaid
flowchart TD
    School["学校Community（Custodian）"] --> Media["Media 2"]
    Media --> Members["学校Communityの参加者全員"]
    Other["別Community"] -. "閲覧不可" .-> Media
```

Community管理Mediaを別Communityへ公開しません。

## 4. 委譲時の公開解除

### UserからUser

```mermaid
flowchart LR
    Before["User A管理・2 Communityへ公開"]
    Transfer["User Bへ委譲"]
    After["User B管理・公開なし"]
    Before --> Transfer --> After
```

### UserからCommunity

```mermaid
flowchart LR
    Before["User管理・複数Communityへ公開"]
    Transfer["Community Aへ委譲"]
    After["Community A管理・A参加者のみ閲覧"]
    Before --> Transfer --> After
```

以前の公開判断は継承しません。

## 5. Mediaの複数Group所属

```mermaid
flowchart TD
    Graduation["2026年 卒業式"] --> Media["Media 3"]
    BrassBand["吹奏楽部"] --> Media
```

同じMediaを複製せず、複数の分類から参照します。

## 6. Groupの単純構造

```mermaid
flowchart TD
    Travel["旅行"] --> Image1["Media 1"]
    Travel --> Image2["Media 2"]
```

## 7. Groupの木構造

```mermaid
flowchart TD
    Travel["旅行"] --> Japan["日本"]
    Travel --> Overseas["海外"]
    Japan --> Tokyo["東京"]
    Japan --> Kyoto["京都"]
```

## 8. GroupのDAG

```mermaid
flowchart TD
    Travel["旅行"] --> Okinawa["沖縄"]
    Summer["夏"] --> Okinawa
    Okinawa --> Media["Media 4"]
```

`沖縄`は`旅行`と`夏`の両方に所属します。循環は許可しません。

## 9. User削除

```mermaid
flowchart TD
    User["削除対象User"] --> M1["Media 1: Userへ委譲"]
    User --> M2["Media 2: Communityへ委譲"]
    User --> M3["Media 3: 物理削除"]
```

すべての管理Mediaを解決してからUserを削除します。

## 禁止パターン

- 1 Mediaを複数Userが共同管理
- 1 MediaをUserとCommunityが共同管理
- Community管理Mediaを別Communityへ公開
- Communityのネスト
- Community内の参加者別Media ACL
- Groupによるアクセス制御
- Group関係の循環
- CustodianがないMedia
