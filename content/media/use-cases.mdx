# Media関連ユースケース


## 概要

> 実装状況: 静止画像を中心とした一部の操作は実装済みです。Media、動画、Custodian、Community共有、Media Eventを含む設計との差分は未実装です。

## Actor

| Actor | 役割 |
| --- | --- |
| User | Mediaをアップロード、管理、共有、分類する |
| Community Member | Community内で共有されたMediaを閲覧する |
| Community Administrator | Communityの参加・管理情報を操作する |
| System | ファイル、メタデータ、関連、Media Eventの整合性を維持する |

## レビュー済みユースケース

### Mediaをアップロードする

- Userが静止画像または動画をアップロードする
- Uploaderとアップロード日時を記録する
- 個人領域ではUser、Communityへの直接uploadではCommunityを初期Custodianとする
- 対応形式以外を拒否する
- UPLOADEDイベントを記録する
- 1 requestで1 Mediaを登録し、幅別Variantを非同期生成する

### Mediaを閲覧・downloadする

- User管理MediaのOriginalはUser Custodianだけがdownloadできる
- Community管理MediaのOriginalはCommunity Administratorと参加中のUploader本人がdownloadできる
- その他のCommunity参加者は表示用Variantを閲覧できるがOriginalはdownloadできない
- 共有先Communityの管理者であっても、User管理MediaのOriginalはdownloadできない
- 退会・除外・User削除後のUploaderはOriginalをdownloadできない

### User管理MediaをCommunityへ共有する

- CustodianであるUserが共有先Communityを選ぶ
- 1つのMediaを複数Communityへ共有できる
- 共有先参加者全員が閲覧できる
- CustodianはUserのまま
- 別の共有先には影響しない

### User管理Mediaの共有を解除する

- 対象Communityとの閲覧関係だけを削除する
- 他Communityへの共有は維持する
- Media本体とCustodianは変更しない

### Mediaを委譲する

管理主体の委譲は初回Release対象外です。[Issue #48](https://github.com/hazuki3417/memoria-design/issues/48)で将来機能として検討します。

対応する遷移はUser→User、User→Community、Community→Userです。

事前条件:

- 操作者が現在のCustodianを変更できる
- 委譲先が存在し、有効である

結果:

- 既存共有をすべて解除する
- Custodianを変更する
- Uploaderは変更しない
- CUSTODIAN_CHANGEDイベントを記録する

### Mediaを削除する

- 復元できないことを表示する
- 物理ファイル、派生ファイル、DBレコードを削除する
- Group関連と共有設定を削除する
- Community管理MediaはAdministratorと参加中のUploader本人が削除できる
- 問い合わせによる個別復元を提供しない

### User削除前に管理Mediaを解決する

- 管理Mediaを表示する
- Mediaごと、複数選択、全件で委譲または削除する
- Media Groupを選択条件として利用できる
- 未処理Mediaがある間はUser削除を完了しない

### MediaをGroupへ追加・除外する

- 1つのMediaを複数Groupへ追加できる
- 追加・除外でCustodianと共有範囲を変更しない
- Groupから除外してもMedia本体を削除しない

### Media Groupを関連付ける

- Groupに親子関係を追加・解除する
- 1つのGroupに複数の親を許可する
- 自己参照と直接・間接の循環を拒否する

## 明示的に対応しないユースケース

| ユースケース | 理由 |
| --- | --- |
| 著作権者を登録・証明する | 正確な判定と権利管理が困難 |
| Mediaを複数主体で共同管理する | 責任・課金主体が曖昧になる |
| Community内で参加者別に共有する | Community内全員共有の目的に反する |
| Community管理Mediaを別Communityへ共有する | Communityの独立性を崩す |
| Community間で直接委譲する | 具体的な利用場面がない |
| Groupでアクセス制御する | 分類と権限が混在する |
| 削除Mediaを復元する | ライフサイクルと問い合わせ対応が複雑になる |
| Word・PDFなどを管理する | Media限定というプロダクト境界外 |
