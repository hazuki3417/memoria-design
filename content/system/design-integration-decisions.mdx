# Design integration archive

このページに置かれていた過去の版・作業時点を基準にした統合方針は、現行設計体系では使用しません。

統合時に採用した重要な判断、旧設計を変更した理由、将来機能とInitial Releaseを分離する意図は [Design Decision / Implementation Traceability](/system/design-decision-traceability) および各Domain / System正本へ統合しています。

現在有効な仕様は [Current design baseline](/context/current-design-baseline) から参照してください。過去資料の版番号や統合作業の分類を、現在の仕様version・優先順位として解釈しません。
