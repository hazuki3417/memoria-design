# 技術スタック

> 状態: 現行調査  
> 調査基準: 各リポジトリの`develop`ブランチ

Memoriaで現在確認できる主要技術と、その位置付けです。採用候補ではなく、実装または実行設定で確認できるものを記載します。

| 分類 | 技術 | 現在の位置付け |
| --- | --- | --- |
| 言語 | Go | `memoria-api` |
| 言語 | TypeScript | `memoria-web`、`memoria-IaC`、`memoria-design` |
| API | GraphQL | WebとAPI間の契約 |
| データストア | PostgreSQL | 現行ドメインデータの主要な永続化先 |
| データストア | MongoDB | APIのドライバー、クライアント初期化、ローカルDocker構成を確認。ただし現行ドメインでの具体的用途は要確認 |
| オブジェクトストレージ | Amazon S3互換ストレージ | Mediaファイルの保存 |
| 認証 | Auth0 | APIの認証・ユーザー連携 |
| 可観測性 | OpenTelemetry、Jaeger | トレースの生成とローカル確認 |
| 開発環境 | WSL2 Ubuntu、Devbox、Docker | ローカル開発と依存ツール |
| インフラストラクチャ | AWS、AWS CDK | 実行環境の定義 |
| バージョン管理 | Git、GitHub | ソース、Issue、PR、リリース |
| ドキュメント | Nextra、MDX、Mermaid | 設計書と図の正本 |

## MongoDBの実装状況

`memoria-api`では次を確認しています。

- `go.mongodb.org/mongo-driver`への依存
- Docker ComposeのMongoDBサービス
- アプリケーション起動時のMongoDBクライアント初期化
- DIコンテナへのMongoDBクライアント受け渡し

一方、現在のUser、Image、ImageGroupサービスが利用するリポジトリはPostgreSQLを中心としており、MongoDBクライアントを使う具体的なドメイン処理は確認できません。MongoDBを廃止するか将来利用するかは、このページだけでは決定せず要確認事項として扱います。

バージョン番号、依存パッケージ、実行設定の正本は各実装リポジトリのmodule・package・Devbox・Docker・IaC設定です。
