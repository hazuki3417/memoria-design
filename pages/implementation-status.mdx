# 実装・設計整合状況

> 状態: 現行調査  
> 最終確認日: 2026-08-15  
> 調査基準: 各リポジトリの `develop`

WebはNext.js App Router、APIはGraphQL→Service→Repository interface→Infrastructure、主永続化はPostgreSQLです。Image、ImageGroup、Tag、Userはアプリケーション処理を確認済みです。Community関連は一部がDB定義まで、MongoDB Contentは現行の主要処理として未確認です。IaCの`MemoriaRecord`は旧名称で、マイクロサービス採用を意味しません。

## 将来設計

Contentを静止画像・動画に限定したMediaへ再定義します。管理主体、Community公開、委譲、Group、User削除、物理削除は[Media設計判断](./media/design-decisions)を正本とします。

## 精査により廃止・統合した資料

| 資料 | 判断 |
| --- | --- |
| Micro Service／Memoria Record | 現行構成と不一致。ユースケースはMediaへ包含 |
| Content・Workspace中心GraphQL | 実行可能schemaと不一致 |
| Presentation／Container | 現行App Router・feature構成と不一致 |
| MongoDB前提validation | 現行API全体の規約として不適切 |
| 一マイクロサービス一stack | 採用しない |
| DAM・APM、log | 可観測性へ統合 |
| 一般的なGo・React Tips | プロダクト固有情報がなく削除 |

今後の要確認はMongoDB・既存Contentの扱い、Image→Media移行、Community実装範囲、動画処理、Media Event保存期間、IaC旧名称変更です。
