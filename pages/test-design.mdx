### Database

#### find
- 存在するデータの検索
  - データが正しく取得できることを確認する
  - assert
    - 検索結果のデータを取得し、期待値と比較して確認する
- 存在しないデータの検索
  - 指定した条件でデータが存在しない場合、何も取得されないことを確認する
  - assert
    - 検索結果が空であることを確認する
- シナリオ
  - 複数の条件でデータを検索し、それぞれの条件に応じた挙動を確認する
    - 例）異なる条件で検索した場合、それぞれの検索結果が期待通りかどうか

#### Insert

- 件数比較
  - データの件数が1件のみ増えることを確認する（one）
  - データの件数がn件のみ増えることを確認する（many）
  - assert
    - Insert前の件数を取得し、期待する件数と比較して確認する
    - Insert後の件数を取得し、期待する件数と比較して確認する
- 例外
  - 例外が発生することを確認する
    例）ユニーク制約に違反するデータをInsertしようとした場合など
  - assert
    - 例外を受け取り期待値と比較して確認する
    - 例外からメッセージを抽出し、期待値と比較して確認する
- データ比較
  - Insertしたデータが期待通りの値か確認する
  - assert
    - Insertしたデータを取得し、期待値と比較して確認する
- シナリオ
  - Insertを繰り返したときの挙動を確認する
    - 例）同じデータをInsertした場合、どのようになるか

#### Update

- 件数比較
  - データの件数が変わらないことを確認する（one, many）
  - assert
    - Update前の件数を取得し、期待する件数と比較して確認する
    - Update後の件数を取得し、期待する件数と比較して確認する
- 例外
  - 例外が発生することを確認する
    - 例）存在しないデータをUpdateしようとした場合、リレーションがあるデータをUpdateしようとした場合など
  - assert
    - 例外を受け取り期待値と比較して確認する
    - 例外からメッセージを抽出し、期待値と比較して確認する
- データ比較
  - Updateしたデータが期待通りの値か確認する
  - Updateしていないデータが変わっていないことを確認する
  - assert
    - データをすべて取得し、期待値と比較して確認する（Update対象、Update対象外含めて一緒に比較）
- setup
  - Update対象が1件のみの場合は、UpdateするデータとUpdateされないデータの2つを用意する
  - Update対象が複数の場合は、Updateするデータを2つ用意し、Updateされないデータの1つを用意する
    - Updateの条件が分岐する場合は、条件に合わせたデータを用意する
- シナリオ
  - Updateを繰り返したときの挙動を確認する
    - 例）同じデータをUpdateした場合、どのようになるか

#### Delete

- 件数比較
  - データの件数が1件だけ減ることを確認する（one）
  - データの件数がn件だけ減ることを確認する（many）
  - assert
    - Delete前の件数を取得し、期待する件数と比較して確認する
    - Delete後の件数を取得し、期待する件数と比較して確認する
- 例外
  - 例外が発生することを確認する
    - 例）存在しないデータをDeleteしようとした場合、リレーションがあるデータをDeleteしようとした場合など
  - assert
    - 例外を受け取り期待値と比較して確認する
    - 例外からメッセージを抽出し、期待値と比較して確認する
- データ比較
  - Deleteしたデータが存在しないことを確認する
  - Deleteしていないデータが残っている・変わっていないことを確認する
  - assert
    - データをすべて取得し、期待値と比較して確認する（Delete対象、Delete対象外含めて一緒に比較）
- setup
  - Delete対象が1件のみの場合は、DeleteするデータとDeleteされないデータの2つを用意する
  - Delete対象が複数の場合は、Deleteするデータを2つ用意し、Deleteされないデータの1つを用意する
    - Deleteの条件が分岐する場合は、条件に合わせたデータを用意する
- シナリオ
  - Deleteを繰り返したときの挙動を確認する
    - 例）同じデータをDeleteした場合、どのようになるか
