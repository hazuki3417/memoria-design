# draw.ioからMDX＋Mermaidへの移行

> 状態: 移行中  
> 移行元: `pages/_drawio/modeling.drawio.svg`

## 方針

既存draw.ioは初期設計と検討経緯を保持する参考資料です。MDX＋Mermaidへ移行済みの情報も含みますが、移行が完了するまで削除・上書きしません。

MDX＋Mermaidを今後の正本とし、draw.ioと矛盾する場合は、承認済みADRとMDXを優先します。

## 読み替え

| 初期設計 | 現在の用語 |
| --- | --- |
| Content | Media |
| Content custodian | Media Custodian |
| Content delegation | Media Custodianの委譲 |
| Content access | MediaのCommunity公開 |
| Content group／Image Group | Media Group |
| Owner（Media） | 使用しない。Custodianとする |

## 完了条件

- draw.io内の確定事項がMDXへ移行されている
- 未検討事項が要確認としてMDXへ記録されている
- draw.ioだけを参照しないと理解できない設計がない
- 移行後のdraw.ioをアーカイブまたは削除する判断が記録されている
