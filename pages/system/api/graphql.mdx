# GraphQL契約

> 状態: 現行方針  
> 実行可能な正本: `memoria-api/schemas/graphql/*.graphql`

このページは設計原則を記録し、型・field・引数の一覧は複製しません。APIはschema、Webはoperation・fragment・生成型を所有します。

- 後方互換な追加を優先します。
- 削除、型変更、nullableからnon-nullへの変更は破壊的変更として移行期間を設けます。
- inputはユースケース単位とし、永続化モデルをそのまま公開しません。
- 内部errorの詳細をresponseへ公開しません。
- paginationは実行可能なschemaと利用画面を根拠に決め、初期資料のRelay例を既定仕様にしません。

現行契約はImage・ImageGroup中心です。Media化は合意済みの将来設計ですが未実装であり、DB、Web、storageを含む移行計画が必要です。旧Content・Workspace・MongoDB中心のschema例は削除します。
