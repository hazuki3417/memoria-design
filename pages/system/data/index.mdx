# データモデル

> 状態: 現行実装調査  
> 実行可能な正本: `memoria-api/schemas/postgres/`

| 領域 | 主なテーブル | 状況 |
| --- | --- | --- |
| User | `users` | アプリケーション処理あり |
| Image | `images`、tag関連 | アプリケーション処理あり |
| Group | `image_groups`、image・親子関連 | アプリケーション処理あり |
| Ownership・Access | User・Community関連 | 一部はDB定義中心 |
| Community | community、membership、owner、history | DB定義中心 |

DBに定義があることと利用可能な機能であることを区別します。Community関連は対応するGraphQL・serviceが未確認です。GroupのDAGは自己参照禁止だけでは多段循環を保証できません。ImageからMediaへの移行は将来設計であり、現行テーブルを資料だけで読み替えません。MongoDB Contentは現行の主要データモデルとして確認できません。

将来モデルは[Mediaデータモデル](/media/data-model)、差異は[実装・設計整合状況](/implementation-status)を参照します。
