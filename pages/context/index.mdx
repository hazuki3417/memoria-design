# Context map

Context mapは人間とAIが正本へ到達する索引で、設計本文を複製しません。

| 目的 | 参照順 |
| --- | --- |
| Web | Issue → `memoria-web`のAGENTS/README → [Web設計](/system/web) → 対象実装 |
| GraphQL・API | Issue → [Media](/media) → [API](/system/api) → [GraphQL](/system/api/graphql) → 実行可能schema |
| DB・storage | Issue → [Mediaモデル](/media/data-model) → [データ](/system/data) → API schema・query |
| IaC | Issue → `memoria-IaC`のAGENTS/README → [IaC](/system/infrastructure) → synth・diff |
| 横断変更 | 契約所有者 → 影響repository → 互換性 → PR・deploy・migration順 |

情報は、現在の合意、承認済み設計・ADR、実行可能なschema・実装、各repositoryの規則、過去記録、AI要約の順で優先します。矛盾は推測で解消せず人間へ報告します。
