# 概要

aws s3の設計情報を記載しています。

## 目的

aws s3の運用・パスの設計情報を記載しています。

## 責務

アプリケーションが扱うコンテンツを配置します。

## パス設計

### コンテンツの配置パス
```sh
images/{image id}/original.{extension}
images/{image id}/preview.webp
images/{image id}/thumbnail.webp
images/{image id}/watermarked.webp
```

**preview.webp**
元画像の原寸サイズを表示するための画像

**thumbnail.webp**
元画像をサムネイルとして表示するための画像。元画像の短編を最大幅とし、画像の中心を切り抜いた正方形のサムネイル画像を作成する。

**watermarked.webp**
著作権などの透過画像を合成した画像（仮で設計）

### ダウンロードコンテンツの配置パス

単一ファイルのダウンロードはオリジナルのファイルに対して署名を付与したURLを返却し、フロントでURLを直接踏んでダウンロードする。
複数ファイルのダウンロードはオリジナルのファイルをまとめてzip化し、ダウンロード専用のパスに配置。その後署名を付与したURLを返却し、フロントでURLを直接踏んでダウンロードする。
また一定期間経過後に自動削除されるようs3側を設定する。
