## go

### ポインタ

**`&`**

変数に対する**参照ポインタを返す**演算子です。

変数の内容が実体の場合は、実体に対する参照ポインタを返します。

e.g.,
```go
var num int = 10
var ptr *int = &num  // ptr は num のアドレスを持つポインタ
```


変数の内容がポインタの場合は、そのポインタを参照する参照ポインタを返します。（二重の間接参照）

e.g.,
```go
var num int = 10
var ptr *int = &num  // ptr は num のアドレスを持つポインタ
var ptrptr **int = &ptr  // ptrptr は ptr のアドレスを持つポインタ
```


e.g.,
```go
type Person struct {
    Name string
    Age  int
}

func main() {
    // 下記はそれぞれ異なるということを解説する記事を作成する
	var example1 *[]Person
	var example2 []*Person
}
```

### range

スライスを `range` で繰り返す場合、 `range` は反復毎に2つの変数を返します。 1つ目の変数はインデックスを返し、2つ目は要素のコピーを返します。


**ループして要素値の値を変える**

インデックス指定で参照し、値を書き換えるように実装してください。

e.g.,
```go
// ok
for i := range people {
    people[i].Age = 2
}

// ng
for i, elm := range people {
    elm.Age = 2
}
```



### go.mongodb.org/mongo-driver

**bson.A**

BSON配列を定義する**スライス**です。

e.g.,
```go
bson.A{"bar", "world", 3.14159, bson.D{{"qux", 12345}}}
```

```json
[
    "bar",
    "world",
    3.14159,
    {
        "qux": 12345
    }
]
```


**bson.D**

BSONオブジェクトを定義する**スライス**です。（順序表現あり）

e.g.,
```go
bson.D{bson.E{"foo", "bar"}, bson.E{"hello", "world"}, bson.E{"pi", 3.14159}}
```

```json
{
    "foo": "bar",
    "hello": "world",
    "pi": 3.14159
}
```

公式は下記のようなサンプルを提供していますが、シンタックスハイライト（警告）が出ます。
警告を回避する場合は上記のように `bson.E` を使用して記述してください。

e.g.,
```go
bson.D{{"foo", "bar"}, {"hello", "world"}, {"pi", 3.14159}}
```

**bson.M**

BSONオブジェクトを定義する**マップ**です。（順序表現なし）

e.g.,
```go
bson.M{"foo": "bar", "hello": "world", "pi", 3.14159}
```

```json
{
    "foo": "bar",
    "hello": "world",
    "pi": 3.14159
}
```
